Welcome to **Gemini Chat Nuke** (JLDN Generational Versioning Schema: `2606.2.0-s`), a client-side Firefox WebExtension designed to perform fast bulk deletion, selection, and management of Google Gemini chat conversations.

## Core Capabilities

1. 💥 **Bulk Chat Deletion:** Select multiple conversations and delete them all automatically in sequence.
2. 🔄 **MutationObserver Integration:** Checkboxes stay active dynamically as you scroll or load more chats.
3. 🌐 **Multi-Language Support:** Fully localized in 8 languages (EN, DE, ES, FR, IT, JA, PT-BR, ZH-CN).
4. 🔒 **Privacy-First:** 100% client-side DOM execution with zero telemetry or data collection.
