## Strategic Vision

**Gemini Chat Nuke** is a robust, client-side Firefox WebExtension designed to perform fast bulk deletion, selection, and management of Google Gemini chat conversations via high-speed DOM automation and MutationObserver injection.

## Generational Backlogs & Horizons

### Generation 2606 (Active Baseline)
- [x] **DOM Injection & MutationObserver:** Auto-detects chat list nodes and injects custom checkboxes.
- [x] **Select Visible & Deselect All:** Granular UI controls for batch deletion.
- [x] **i18n Multi-Language Support:** Fully localized in German, Spanish, French, Italian, Japanese, Portuguese (BR), and Simplified Chinese.
- [x] **Orange Team Legacy Modernization:** Full baseline scaffolding, CI quality gate, and CodeQL security suite.

### Generation 2608+ (Future Tooling)
- [ ] **Date-Range Filtering:** Filter conversations by age before selecting for deletion.
- [ ] **Cross-Browser Packaging:** Chrome/Chromium and Safari Manifest v3 compatibility ports.
- [ ] **Bulk Export Pipeline:** Export selected conversations to local Markdown/JSON archives prior to deletion.
